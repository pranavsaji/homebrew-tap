# Homebrew tap for Talktomyhand

[Talktomyhand](https://talktomyhand-api.vercel.app/) is voice dictation for the Mac: hold fn, speak, and clean text appears at your cursor.

```sh
brew install pranavsaji/tap/talktomyhand
```

Update with `brew upgrade talktomyhand`. Needs macOS 14 or later on Apple silicon.
